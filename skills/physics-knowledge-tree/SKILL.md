# 中文物理知识树 — 编辑指南

## 1. 项目结构速览

```
physics-knowledge-tree/
├── site/                 # 可视化网站（双击 index.html 即可离线打开，勿手动改 data/graph.js）
├── content/              # 知识树源文件（本 skill 主要操作此目录）
│   ├── _meta.yaml        # 领域/颜色/云图参数/可视化参数
│   └── <domain>/*.md     # 每个知识点一个 .md 节点文件
├── build.py              # 构建脚本：解析 content → site/data/graph.js + 校验
├── logs/YYYY-MM-DD.md    # 每次编辑的日志
└── skills/physics-knowledge-tree/SKILL.md  # 本文件
```

## 2. 标准工作流（每次编辑必须遵守）

1. **先搜索再新建**：检查 `content/` 中是否已存在同名或同义节点（用 `grep` 搜索中文名/别名），避免重复节点。
2. **编写/修改节点文件**（格式见下节）。
3. **运行校验**：`python build.py`，修复所有警告（warning）。要求 0 警告。
4. **写日志**：在 `logs/` 下追加（或新建）当天的 `YYYY-MM-DD.md`，记录新增/修改的内容（见第 7 节）。
5. 若需要，提示用户重新打开/刷新 `site/index.html` 查看效果。

## 3. 节点文件格式（核心）

每个节点 = YAML front-matter（元数据）+ Markdown 正文。模板：

```markdown
---
id: your-theory-id              # 必需。kebab-case 英文 slug，全树唯一
name: 理论中文名                # 必需。唯一，勿与其他节点重复
name_en: English Name           # 可选
domain: classic-mechanics       # 必需。对应 _meta.yaml 中的领域 id
aliases: [别名A, 别名B]          # 可选。供搜索，尽量覆盖常见叫法
tags: [标签1, 标签2]             # 可选
keywords: [关键词]               # 可选。补充搜索
updated: 2026-08-12             # 与日志日期一致
pos: {x: 0, y: 0, z: 0}         # 可选。手动固定主干节点的初始位置
fixed: false                    # 可选。true 则锁定位置
size: 60                        # 可选。手动覆盖节点体积；缺省自动由连接数计算
links:
  - {id: related-node-id, weight: 4, note: 关系说明}
  - {id: another-id, weight: 2}
superseded_by: [newer-theory-id]   # 可选。本理论被哪些更上位理论替代/涵盖
supersedes: [older-theory-id]      # 可选。本理论替代了哪些旧理论
---
# 标题（与 name 一致）

## 概述
定义 + 物理图像 + 在学科体系中的位置，给出核心结论公式。

## 基本概念
关键概念的精确定义、符号约定、物理量纲。
- 概念 A：定义……
- 概念 B：定义……

## 核心内容
### 基本定律 / 方程
核心方程（KaTeX 独立公式），逐项解释其物理意义。

### 推导要点
从基本原理出发的关键推导步骤（给出关键步，不必逐行展开）。

### 重要定理与推论
由核心内容导出的定理、守恒律、特殊情形等。

## 深化内容
推广、现代视角、更一般理论、前沿与未解问题。
（末尾可用文字提及标准教材名作延伸参考，不引用本地文件）

## 与其他知识的联系
用 [[节点id]] 双向链接，优先引用"直接相连"的节点。
- 紧密相关：[[lagrangian-mechanics]]——说明……
- 相关：[[conservation-laws]]……
- 更远：[[fluid-mechanics]]……

## 上位替代
（可选）当本理论在某种情形下被更上位理论取代时，说明适用边界并链接：
- [[special-relativity]]：高速情形……

## 前置知识
（可选）数学/物理前置：[[calculus]]、[[vector-calculus]]
```

章节说明：`概述`、`基本概念`、`核心内容`、`深化内容`、`与其他知识的联系` 为**必选**；`上位替代`、`前置知识` 为**可选**（按主题取舍）。

### `[[id]]` 与 `[[id|显示名]]`
正文中用双链引用其他节点，`build.py` 会校验目标是否存在（不存在的目标会报警告）。引用时显示节点名，如需不同文字用 `[[id|自定义文字]]`。

## 4. 字段语义

| 字段 | 说明 |
|---|---|
| `id` | 英文 slug，**一旦创建不要改名**（会被其他节点引用）。如确需改名，必须全局搜索替换所有引用。 |
| `name` | 中文名，唯一。避免同义词节点（如"量子力学"与"量子理论"只应有一个）。 |
| `domain` | 领域 id，须在 `content/_meta.yaml` 的 `domains:` 中定义。 |
| `links[].weight` | 1~5 的整数。**语义（务必遵守）**：5=几乎等价/直接可推导（如牛顿力学↔拉格朗日力学）；4=强关联，一个的掌握直接依赖另一个；3=相关，共享概念/方法；2=弱相关；1=边缘背景。权重同时决定图上距离（越大越近）与展示优先级。 |
| `links[].note` | 关系说明，会展示在详情面板。 |
| `superseded_by` | 上位替代（本理论在更大适用范围下由谁取代）。会渲染为紫色虚线箭头 + 详情页"上位替代"横幅。 |
| `supersedes` | 被本理论替代的旧理论（反向关系）。 |

## 5. 连接管理规则

- 每个节点**优先连关系最紧密的节点**（weight 高的在前）。
- 系统中每个节点最多展示 `max_visual_degree`（默认 8）条直接连线；超出部分会自动降级为"软连接"（详情面板 + 2D 视图外圈显示，正文中用 `[[id]]` 超链接直达）。**你仍然可以自由写更多 links**——系统自动处理展示剪枝。
- 对称关系：如果 A 与 B 互相关联，两个文件里都要有对应条目（方向相反、note 可不同）。
- 上位替代关系要"双向成对"：A `superseded_by` B 时，B 应 `supersedes` A。
- **修改内容的原则**：新增知识点时，若它的存在让某个旧节点"过时/被涵盖"，务必在该旧节点中加 `superseded_by` 并说明边界。

## 6. 内容写作规范（扩充标准）

**定位**：面向物理专业学生，教材级详尽、较强的专业性——不满足于罗列核心结论，需补充完整的基础（定义、推导、定理）与深化内容（推广、现代视角、前沿）。

**篇幅**：每个节点正文 1500~2500 字、8~25 个公式；工具型/边缘节点可适当精简（≥800 字）。

**章节要求**：
- 必选：`## 概述`、`## 基本概念`、`## 核心内容`、`## 深化内容`、`## 与其他知识的联系`。
- 可选：`## 前置知识`、`## 上位替代`（被更上位理论取代时才写）。
- `## 核心内容` 下设 `### 基本定律 / 方程`（逐项解释物理意义）、`### 推导要点`（关键步骤）、`### 重要定理与推论`。

**公式规范**：
- 一律 KaTeX：`$...$`（行内）、`$$...$$`（独立成行）；LaTeX 语法。
- 公式前后用一两句话解释其含义与物理意义，做到"可读"。
- 推导给出关键步骤，不必逐行展开；符号在前文定义、全文一致。

**专业严谨性**：
- 以标准物理/数学知识体系为准，内容与现代共识一致，不写无来源断言、不编造结论。
- 符号、单位、量纲正确；区分物理量符号与算符（如矢量 $\vec E$、算符 $\hat H$）。
- `[[id]]` 只指向已存在的节点（`build.py` 校验，保持 0 警告）。

**教材参考**：在 `## 深化内容` 末尾用文字提及标准教材名（如朗道《力学》、Griffiths《电动力学》、Sakurai《现代量子力学》、Pathria《统计力学》等）作延伸阅读，**不引用任何本地文件**。

**领域侧重点**：数学节点侧重"定义-定理-证明-例子"；物理节点侧重"定律-推导-物理意义-应用"；上位/下位替代理论务必在 `## 上位替代` 说明适用范围与失效边界。

## 6.1 分批扩充流程

- 按领域分批推进（优先级：数学基础 → 经典力学 → 电动力学 → 量子力学 → 统计物理 → 相对论/数理方法 → 量子场论/粒子物理 → 其余领域）。
- 每批完成若干节点后：`python build.py` 要求 0 警告，并在 `logs/` 追加日志（新增/修改节点、批次范围）。
- 扩充既有节点时：保留 front-matter 的 `id/name/domain`，可补 `aliases/keywords`；仅改写正文；`updated` 更新为当天日期。

## 7. 日志规范

每次编辑会话**必须**在 `logs/` 写入（或追加）当天文件。格式：

```markdown
# 2026-08-12 编辑日志

## 新增节点
- 电动力学/麦克斯韦方程组.md —— 统一电磁学，预言电磁波
- 量子力学/薛定谔方程.md —— 量子力学基本方程

## 修改节点
- 经典力学/牛顿力学.md —— 新增上位替代：狭义相对论/量子力学

## 新增/修改连接
- 麦克斯韦方程组 → 电磁波（weight 5）
- 牛顿力学 → 特殊相对论（上位替代）

## 说明
（补充任何决策或待办事项）
```

日志中的日期应与相关节点的 `updated` 字段一致。

## 8. 新增领域（domain）

如需添加领域（如"核物理"、"等离子体"）：

1. 在 `content/_meta.yaml` 的 `domains:` 下添加条目，格式：
   ```yaml
   nuclear-physics:
     name: 核物理
     color: "#fdcb6e"
     cloud_alpha: 0.09
     cloud_r: 1.0
   ```
2. `color` 用十六进制，尽量与其他领域区分明显。
3. 在 `content/nuclear-physics/` 下建目录并写节点。
4. 运行 `build.py` 确认领域出现在图例与统计中。

## 9. 校验与构建

```bash
cd physics-knowledge-tree
python build.py            # 构建 + 校验，输出统计与警告
```

预期结果：
- `0 警告`；若有警告必须逐个修复（多为：引用不存在的节点 id、重复 id、领域未定义、weight 越界、`[[id]]` 指向不存在节点）。
- 构建会输出节点数、连接数、上位替代边数、领域分布。
- `site/data/graph.js` 由脚本生成，**禁止手改**。

## 10. 常见错误与排查

| 症状 | 原因与处理 |
|---|---|
| `[文件] 重复 id` | 该 id 已被其他文件使用，换个唯一 id。 |
| `link 指向不存在的节点` | 先创建目标节点，或删掉该链接。 |
| `[[xxx]] 引用了不存在的节点` | 正文双链指向了未创建的 id，修正为已存在的 id。 |
| `领域 'x' 未定义` | 在 `_meta.yaml` 中补领域。 |
| 图里看不到新节点 | 先跑 `python build.py`，再刷新 `site/index.html`。 |
| 图例不显示新领域 | `_meta.yaml` 领域 id 与节点 `domain` 不一致。 |

## 11. 网站使用提示（供参考，无需修改）

- 打开 `site/index.html` 即 3D 全局视图：滚轮缩放、拖拽旋转。
- **单击节点**：高亮该节点、与之相连的所有节点与路径（其余节点/连线弱化）。
- **双击节点**：进入该节点——切换为 2D 平面视图（该节点居中 + 全部相连节点），右侧详情抽屉显示内容与公式。
- 2D 视图中：单击高亮、双击切换中心；点击空白或"← 返回 3D 全局"返回。
- 顶栏"字号"滑杆调节 3D 节点标签字体（刷新后保留）；"间距"滑杆（2D 模式显示）调节节点间距，节点可自由拖动（释放后固定），"重置布局"复位。
- 顶部搜索框按名称/别名/标签/关键词检索，回车/点击直接跳转进入节点。
- "领域图例"可逐域隐藏；"标签"开关节点文字。
- "学习树"开关左侧树状学习图：双击/搜索进入的节点按相关度挂到最相关根下（强相关正常、弱相关弱化、无相关询问建新根）；正文超链接进入无条件挂到最近根下；支持拖拽改父子、设为根、移除、折叠；可"保存"命名存入森林、"森林"载入/删除，`localStorage` 自动长期保存。
- "挑战模式"开关挑战玩法：以每领域 importance 最大的节点为核心节点起步，每轮把随机出现的子节点（仅显示名称）挂到正确父节点；宽松/严格判定可选、答错逐级提示、全程计时。
